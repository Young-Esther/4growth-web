## 1. 전역 규칙

**사이트 구조**
- 단일 페이지 `/` + 앵커 이동. 헤더 메뉴는 앵커 링크.
- `/contact`는 만들지 않음. 문의는 HOME 하단 `#contact`. QR은 `https://{도메인}/#contact`로 연결.

**헤더 (고정, 스크롤 시 흰 배경 + 얇은 하단선)**
- 좌: 4GROWTH 로고
- 우: `Technology` `Field` `Applications` `Contact` (각각 #technology #field #applications #contact)
- 모바일: 햄버거 → 풀스크린 메뉴

**디자인 토큰 (카탈로그 시안 기준)**
- 배경 `#FFFFFF`, 본문 텍스트 `#231F20`
- 포인트 블루 `#4366B9` (카탈로그 뒷표지·CTA 바 색)
- 로고 그린: AI 원본에서 추출 `[확인 필요]` — 로고 외에는 사용하지 않음
- 보조 회색: `#F4F5F7` (카드 배경), `#6B7280` (캡션, 흰 배경 대비 4.8:1), `#E5E6EA` (경계선)
- 폰트: Pretendard (jsdelivr CDN, `font-display: swap`). 제목 Bold, 본문 Medium/Regular. 영문 라벨은 letter-spacing 0.08em, 대문자.
- 섹션 라벨: 카탈로그처럼 좌상단 소문자 영문 라벨 + 번호 (예: `01 — TECHNOLOGY`)
- 여백: 섹션 상하 `py-24` (모바일 `py-16`), 컨테이너 최대폭 1200px
- 문장 원칙: 한 줄 헤드라인 + 2~3줄 본문. 장문 금지.
- 애니메이션: v0.1은 fade-in on scroll 한 종류만. 그 외 없음. (Field 캐러셀의 스크롤 스냅은 브라우저 기본 동작이며 연출 애니메이션이 아님)

**상태 태그 컴포넌트**

## 4. SECTION 03 — 세 기술 상세 (3 카드, 세로 배치)

각 카드: 좌 텍스트 / 우 이미지, 카드마다 좌우 반전. 모바일은 텍스트 → 이미지.

### 03-A. A-Block
- 라벨: `A-BLOCK — Modular Growing Space`
- Headline: **필요한 만큼 짓고, 필요한 곳으로 옮깁니다.**
- Body (카탈로그 4p): A-Block은 알루미늄 프로파일 프레임과 폴리카보네이트 패널로 구성된 반개방형 모듈 재배 유닛입니다. 현장에서 조립·해체할 수 있고, 규모에 따라 모듈 단위로 확장됩니다. 센서와 제어부가 모듈 안에 통합되어 있어 별도의 설비 공사 없이 재배 환경을 관리할 수 있습니다.
- 4 포인트 (2×2 그리드):
  - 01 모듈형 구조 — 현장 조립·해체, 이설 가능
  - 02 단계적 확장 — 모듈 단위로 규모 조정
  - 03 통합 제어 — 센서·제어부 내장
  - 04 반개방형 설계 — 자연광 활용, 밀폐형 대비 에너지 절감
- Visual: 카탈로그 5p 구조도(아이소메트릭 SVG I-03) + 하단에 `1 MODULE → 2 MODULES → 3 MODULES` 확장 그림 (I-04)
- 상태 태그: `개발 중 · 시제품 제작 단계`

### 03-B. DLight
- 라벨: `DLIGHT — DLI-based Light Control`
- Headline: **식물은 빛이 계속 필요한 것이 아니라, 필요한 만큼의 빛이 필요합니다.**
- Body (카탈로그 6p): 작물마다 하루에 필요한 누적 광량(DLI)이 다릅니다. 고정 타이머 방식은 자연광이 충분한 날에도 같은 시간만큼 LED를 켭니다. DLight는 유입되는 자연광을 실시간으로 측정하고, 목표 광량에서 부족한 만큼만 LED로 보충합니다.
- 참고: 출원 명세서는 카탈로그 설명보다 범위가 넓음 (구역별 광전달 모델 자동 학습, 예보 과대예측 보정, 전력 상한 내 점등 시점 사전 편성). v0.1은 카탈로그 문장 유지, v0.5 Technology 페이지에서 확장. 시뮬레이션 수치(절감률 등)는 실증 전이므로 홈페이지에 쓰지 않음.
- Visual: 카탈로그 6p 그래프 (자연광 곡선 + LED 보충분, 목표 누적광량선) — SVG로 재제작. 좌측 플로우(자연광 유입 → 센서 측정 → 누적 DLI 산출 → 목표와 비교 → 부족분만 LED 출력)는 캡션 5줄로 축약.
- 상태 태그: `개발 중 · 현장 검증 진행 중` `특허 출원`

### 03-C. AI Farm OS
- 라벨: `AI FARM OS — Data & Control`
- Headline: **하나의 농장을 하나의 시스템에서**
- Body (카탈로그 7p): 센서가 수집한 환경 데이터와 재배 기록은 AI Farm OS에 모입니다. 환경 모니터링, 광량 관리, 장치 제어, 재배 이력을 한 화면에서 관리하고, 축적된 데이터를 기반으로 재배 리포트를 자동 생성합니다.
- 5 기능 (아이콘 리스트):
  - 환경 모니터링 (온습도 · CO₂ · 광량)
  - DLI 누적 및 광량 관리
  - 장치 제어
  - 재배 이력 및 생육 데이터 관리
  - 재배 리포트 자동 생성
- Visual: Farm OS 화면 캡처 (카탈로그 7p 것) — 노트북/브라우저 프레임 없이 그림자만. 하단에 데이터 흐름 `FARM → SENSOR → DATA → AI → CONTROL` 한 줄 스트립.
