## 1. 라우팅 & 다국어

- 라이브러리: `next-intl` (App Router). 로케일 `ko`(기본) · `en` · `vi`, `localePrefix: 'always'`.
- 메시지: `messages/ko.json`, `messages/en.json`, `messages/vi.json`. 내용은 `docs/COPY.md` 그대로.
- 구조: `app/[locale]/…`. `<html lang>`은 로케일 값.
- `/` 접속 시 미들웨어:
  - `NEXT_LOCALE` 쿠키가 있으면 그 언어로 보낸다.
  - 쿠키가 없으면 브라우저 언어를 본다. vi → `/vi`, en → `/en`, 그 외 → `/ko`.
- 언어 전환 시 같은 경로의 다른 로케일로 이동한다 (`/ko/business/chadam` → `/vi/business/chadam`). 선택은 쿠키에 저장한다.
- 번역 누락 키는 ko로 폴백한다. 빌드 시 누락 키를 경고 목록으로 출력한다.
- 폰트: Pretendard 유지. **vi 페이지에서 성조 부호(ạ ế ữ ờ 등)가 다른 폰트로 섞여 보이면**, vi 로케일에만 `Be Vietnam Pro`(next/font/google, 400/500/700)를 본문 폰트로 적용한다. 375px 실기기 스크린샷으로 확인한다.

## 2. 헤더

- 좌: 로고 → `/{locale}`
- 우: 메뉴 `기술` `사업영역` `소식` `문의` (현재 페이지는 블루 + 굵게) + 언어 전환 `KO · EN · VI`
  - 언어 전환 표시: 현재 언어는 굵게 + 블루, 나머지는 회색 `#6B7280`. 구분자 `·`. 드롭다운 아님.
- 모바일: 로고 | `KO · EN · VI` | 햄버거.
  - **언어 전환은 메뉴를 열지 않아도 보여야 한다.** 박람회 현장에서 QR로 들어온 사람이 바로 바꿀 수 있어야 하기 때문이다.
- 고정 헤더, 스크롤 시 흰 배경 + 하단선 (v0.1과 동일).

### 3-5. 소식 `/news`, `/news/[slug]`
- 콘텐츠는 파일로 관리한다. CMS는 쓰지 않는다.
  ```
  content/news/<slug>/ko.md   (필수)
  content/news/<slug>/en.md   (선택)
  content/news/<slug>/vi.md   (선택)
  public/news/<slug>/cover.jpg (선택)
  ```
  frontmatter: `title`, `date`(YYYY-MM-DD), `category`(`event` | `trial` | `award` | `notice`), `summary`(1줄), `cover`(선택)
- 파싱: `gray-matter` + `remark`/`remark-html`(또는 동급 경량 라이브러리). `generateStaticParams`로 정적 생성한다.
- 해당 로케일 파일이 없으면 ko 본문을 보여준다. 이때 상단에 안내 1줄을 띄운다 (COPY: "이 글은 한국어로만 제공됩니다").
- **목록**: 페이지 헤더 + 카테고리 칩(전체 / 박람회·행사 / 실증·설치 / 선정·수상 / 공지, `?category=`로 필터) + 카드 리스트. 날짜 내림차순. 카드에는 커버(있을 때만), 카테고리 pill, 날짜, 제목, 요약을 표시한다.
- **상세**: 카테고리 pill + 날짜 + 제목 + 커버 + 본문 + `목록으로`.
- 날짜 형식: ko `2026.09.30` / en `Sep 30, 2026` / vi `30/09/2026`.
- **초기 게시물 규칙**: 검증된 사실만 올린다. `[확인 필요]`가 남은 글은 `draft: true`로 두고 빌드에서 제외한다.
  - `dlight-patent` (notice, 2026-08-24) — 내용 확정. 바로 게시
  - `vietnam-expo-2026` (event) — 박람회 정보 받으면 게시
  - `agri-expo-2026-09` (event) — 명칭 확정 시 게시
  - `chungnam-idea-final` (award) — 발표일 확정 시 게시

## 4. 기존 QR·링크 호환 (필수)

인쇄된 카탈로그 QR은 `https://4growth.co.kr/#contact`를 가리킨다. **이 주소는 계속 문의 화면에 도착해야 한다.**
- `/` → `/{locale}` 리다이렉트 시 브라우저는 `#contact` 해시를 유지한다. 실기기에서 확인한다.
- 홈에 클라이언트 컴포넌트 `LegacyHashRedirect`를 둔다. 해시별 이동:
  - `#contact` → `/{locale}/contact`
  - `#technology` → `/{locale}/technology`
  - `#applications` → `/{locale}/business`
  - `#field` → 홈 그대로 (해당 섹션으로 스크롤)
- `router.replace`를 쓴다 (뒤로가기 기록을 남기지 않기 위해).
