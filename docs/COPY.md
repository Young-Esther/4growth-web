### DLight
| KO | EN | VI |
|---|---|---|
| 식물은 빛이 계속 필요한 것이 아니라, 필요한 만큼의 빛이 필요합니다. | Plants don't need light all the time. They need just the right amount. | Cây trồng không cần ánh sáng liên tục, mà cần đúng lượng ánh sáng cần thiết. |
| 작물마다 하루에 필요한 누적 광량(DLI)이 다릅니다. 고정 타이머 방식은 자연광이 충분한 날에도 같은 시간만큼 LED를 켭니다. DLight는 유입되는 자연광을 실시간으로 측정하고, 목표 광량에서 부족한 만큼만 LED로 보충합니다. | Every crop needs a different Daily Light Integral (DLI). Fixed timers run LEDs for the same hours even on sunny days. DLight measures incoming natural light in real time and uses LEDs to supply only what is missing from the target. | Mỗi loại cây trồng cần lượng ánh sáng tích lũy trong ngày (DLI) khác nhau. Phương thức hẹn giờ cố định vẫn bật đèn LED với cùng thời lượng ngay cả vào những ngày đủ nắng. DLight đo ánh sáng tự nhiên theo thời gian thực và chỉ dùng đèn LED bù phần còn thiếu so với mục tiêu. |
| 자연광 유입 | Natural light enters | Ánh sáng tự nhiên chiếu vào |
| 광량 센서 측정 | Light sensor measures | Cảm biến đo ánh sáng |
| 현재 누적 DLI 산출 | Current DLI is calculated | Tính DLI tích lũy hiện tại |
| 목표 DLI와 비교 | Compared with target DLI | So sánh với DLI mục tiêu |
| 부족분만큼 LED 출력 조절 | LED output fills the gap | Điều chỉnh đèn LED bù phần thiếu |
| 목표 광량에서 부족한 만큼만 LED로 보충 | LEDs supply only what's missing from the target | Đèn LED chỉ bổ sung phần thiếu so với mục tiêu |
